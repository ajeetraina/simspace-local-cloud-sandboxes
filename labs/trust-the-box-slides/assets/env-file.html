An environment file describes the whole sandbox

# sbxenv.yaml — committed to the repo
schemaVersion: "1"
name: web-app
agent: claude
workspace: ./web-app
kits:
  - sbx/playwright-kit:latest
sandboxOptions:
  cpus: 4
  memory: 8g

Agent

Which harness the sandbox runs

Workspace

The project folder the agent can see

Kits

Tools, credentials, and network rules come with each kit

Resources

CPU and memory for the sandbox

Start it with sbx env run · experimental, format may change
